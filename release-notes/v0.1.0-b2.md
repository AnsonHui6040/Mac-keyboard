# Remote Keyboard v0.1.0（build 2）測試版

重新整理 iPhone App 與 Mac 面板，加入教學，並修正配對與觸控板的問題。

安裝與更新前，請先閱讀[使用手冊](https://github.com/AnsonHui6040/Mac-keyboard/blob/main/docs/manual/README.md)。請不要把 Apple 帳號密碼或雙重驗證碼交給任何人，包括開發者。

## 需求

| 裝置 | 版本 |
|---|---|
| iPhone | iOS 18 以上 |
| Mac | macOS 15 以上，Apple 晶片 |

## 本版變更

### iPhone App

- 首頁改為設定進度與分類：鍵盤回饋、觸控板、中文輸入與手寫、聽寫。
- 第一次打開時有四頁引導，之後可以在「使用教學」重看。
- 鍵盤上次連不上 Mac 或配對驗證失敗時，首頁會指出問題與處理方式。
- 底部加入 GitHub 連結與法律聲明。

### Mac Receiver

- 面板重新排列，警告放在最上方，連線與目前欄位改用一般用語。
- 未配對時顯示三步提示，「使用教學」開啟教學視窗。

### 修正

- 鍵盤還在畫面上時開啟配對視窗，驗證失敗後 iPhone 無法完成配對。
- 沒有發出配對請求的裝置可能佔住配對連線。
- 觸控板收到連續錯誤封包後失效，現在會自動重新開啟。
- 手勢進行中螢幕休眠或拔除時，游標可能停住。
- 單一字元過長時可能被截斷。
- 手寫模型匯入失敗時，顯示正確的提示。
- 切換 App 時，舊的鍵盤畫面可能關掉按鍵音或觸控板。
- iPhone 的配對金鑰不再隨備份搬到另一部裝置。

## 從 build 1 更新

1. iPhone：用 SideStore 匯入新的 IPA，不要先刪除舊版。詢問 Extension 時選「Keep App Extensions (Register App ID for Each Extension)」。
2. Mac：用新的 zip 取代舊的 App，再到「系統設定 > 隱私權與安全性 > 輔助使用」重新開啟 Remote Keyboard Receiver。
3. 配對通常會保留。鍵盤顯示「配對驗證失敗」時，兩邊重新配對即可。

SideStore 登入出現 `-80045` 時，請見手冊的[疑難排解](https://github.com/AnsonHui6040/Mac-keyboard/blob/main/docs/manual/10-troubleshooting.md)。

## 已知限制

- 部分終端機的密碼提示、遠端桌面內的欄位等可能偵測不到，請不要用這個鍵盤輸入密碼。
- 其他 App 開著安全輸入時，一般欄位也會顯示「密碼不能輸入」。
- Receiver 閒置 30 分鐘會停止接收，要在 Mac 點一下文字欄位或按「開始接收」。
- 免費帳號簽署的 App 只有 7 天有效，要定期續簽。
- 連線不穩時，文字可能遺漏或重複。
- Mac App 沒有經過公證。更新版本後，要重新授權輔助使用，也可能要重新授權藍牙。
- 一方按確認、另一方取消配對時，兩邊的金鑰會不一致，重新配對即可。
