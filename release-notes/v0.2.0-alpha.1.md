# Remote Keyboard v0.2.0 Alpha 1

這一版讓 iPhone 的 Remote Keyboard 可以同時連到 Mac、Windows 11 與 Ubuntu 26.04 電腦。iPhone 可以記住最多 8 台電腦，在鍵盤的狀態格點一下就能切換；每台電腦也可以記住最多 8 支手機。Alpha 代表功能還會調整，也可能有問題，請不要用在重要工作上。

安裝與更新前，請先閱讀[使用手冊](https://github.com/AnsonHui6040/Mac-keyboard/blob/main/docs/manual/README.md)。請不要把 Apple 帳號密碼或雙重驗證碼交給任何人，包括開發者。

## 需求

| 裝置 | 版本 |
|---|---|
| iPhone | iOS 18 以上 |
| Mac | macOS 15 以上，Apple 晶片 |
| Windows | Windows 11，x64 |
| Linux | Ubuntu 26.04，x86_64，GNOME 桌面，Wayland 工作階段 |

電腦都需要支援 Bluetooth LE 的藍牙，並且已開啟。

## 下載

| 檔案 | 用途 |
|---|---|
| `RemoteKeyboard-Setup-0.2.0-alpha.1.exe` | Windows 安裝程式，裝在使用者資料夾，不需要系統管理員權限 |
| `remote-keyboard_0.2.0~alpha.1_amd64.deb` | Ubuntu 套件，用 `sudo apt install ./remote-keyboard_0.2.0~alpha.1_amd64.deb` 安裝 |
| Mac Receiver 的 zip 檔 | macOS 接收端，安裝方式見手冊第 04 章 |
| iPhone 的 IPA 檔 | 用 SideStore 安裝 |
| `SHA256SUMS.txt` | 安裝檔的 SHA-256 值，安裝前請先核對 |

## 新功能

- Windows 接收端：系統匣圖示與選單、安裝程式、開機自動啟動、文字輸入（含中文）、觸控板。
- Linux 接收端：系統匣圖示與選單、`.deb` 套件、開機自動啟動、文字輸入、觸控板。第一次執行要允許「遠端桌面」。
- 多台電腦：iPhone 最多記住 8 台電腦，鍵盤的狀態格顯示目前電腦的名稱，點一下切換。App 首頁的「已配對電腦」可以新增、刪除與指定目前電腦。
- 多支手機：每台電腦最多記住 8 支手機，可以個別刪除。
- 電腦名稱：接收端的選單可以改名，手機上會顯示這個名稱。
- 接收開關：三個平台的接收端都有「停止接收」與「開始接收」。
- 診斷：接收端可以匯出診斷資料，log 只記事件種類、長度、時間與結果，沒有打字內容。

## 從 v0.1 升級

1. 這一版的通訊協定是 v4，與 v0.1 不相容。iPhone App 與 Mac Receiver 都要更新到這一版。
2. 更新後，原有的配對全部失效，每台電腦都要重新配對，見手冊第 05 章。
3. iPhone：用 SideStore 匯入新的 IPA，不要先刪除舊版。
4. Mac：用新的 zip 取代舊的 App，並重新允許輔助使用，見手冊第 04 章。
5. Windows：直接執行安裝程式。若電腦上已有手動複製的舊版，安裝程式會先關閉它，再覆蓋安裝。
6. Linux：從 `~/.local/bin` 手動複製的舊版，先刪除那份，再安裝 `.deb`。

## 使用前請注意

- Windows 與 Linux 接收端沒有焦點安全閘：文字會送到目前最前面的視窗，包括密碼欄。請不要用這個鍵盤輸入密碼。Mac Receiver 仍會擋下系統標示的密碼欄。
- Windows：以系統管理員身分執行的視窗、UAC 提示與鎖定畫面收不到輸入。
- Windows 安裝檔沒有簽章，第一次執行時 SmartScreen 會警告，按「其他資訊」再按「仍要執行」。
- Linux：非 ASCII 文字（例如中文）預設用貼上輸入，會覆蓋電腦的剪貼簿。可以在系統匣選單取消「非 ASCII 文字改用貼上」，但之後只能直接打出 Latin-1 範圍的字元。
- 免費帳號簽署的 iPhone App 只有 7 天有效，要定期續簽。
- Mac App 沒有經過公證。

## 已知限制

- Linux 上手機連線的速度較慢：服務探索約需 2.4 秒，重新連線的 p95 約 7 秒。Linux 的預設藍牙連線間隔較長，觸控板可能有延遲感。手冊第 04c 章列出選用的 root 指令，可以縮短指定藍牙卡的連線間隔，重新開機後要再執行一次，接收端不會替你執行。
- 連線不穩時，文字可能遺漏或重複。
- 只支援上表列出的系統，其他系統即使能執行也未經測試。

## 尚未在實機驗證

- Windows 安裝程式覆蓋舊的手動安裝，與解除安裝後的狀態。
- Linux `.deb` 取代 `~/.local/bin` 的舊版，以及登入後的自動啟動。
- 三台電腦都用安裝檔裝好之後的整合驗收。
- 系統匣各項操作、改名、刪除手機與匯出診斷資料。
- Linux 鑰匙圈鎖住時的實際提示，以及藍牙控制器切換。
