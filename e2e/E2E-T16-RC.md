# E2E-T16-RC：發布前實機總清單

執行者：使用者。這份清單把所有延到最後才測的實機項目合在一起，依「同一個準備狀態一起做」排序，不必再翻各份 E2E 檔。使用者親手測完才算 PASS；在那之前，結果欄一律維持 TBD。

怎麼填：測完一列，把結果欄的 TBD 改成 `PASS` 或 `FAIL（看到的現象）`。需要記錄數字的列，直接把數字寫在結果欄。

欄位說明：

| 欄位 | 意思 |
|---|---|
| 必要 | 沒有通過就不能發布 |
| 可選 | 建議測，沒測或失敗只記錄，不擋發布 |
| 來源 | 原本放這一項的 E2E 檔與步驟號，需要細節時回去看 |
