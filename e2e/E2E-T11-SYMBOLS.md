# E2E-T11-SYMBOLS：符號頁真機驗收

執行者：使用者。所有結果在使用者親手測完之前維持 TBD。依 `defer-device-tests-to-t16` 的決定，本份實機驗收延至 T16 一併執行。

通過標準：
- 英文符號頁兩層、中文符號頁三層的每一顆鍵，在本機（備忘錄）與遠端（Mac TextEdit）各打一次，輸入的字元與鍵面一致。
- 換層鍵只改變本頁顯示，不送出任何字；來回切換層與頁面都不會重複送出。
- 每次進入符號頁都從第 1 層開始；由中文頁進入先看到全形標點，由英文頁進入先看到數字與半形標點。
- 刪除鍵長按連續刪除，行為與英文頁相同。

自動驗證（不需真機）：`SymbolLayoutsTests`（五項版面測試加列數與換層鍵標示）、模擬器預覽截圖（402 pt、375 pt，五個符號狀態）。

## 前置條件

- iPhone 以線連接 Mac 並解鎖，已用 Xcode 安裝本分支的 Remote Keyboard，已開啟「允許完整取用」，並已完成 Mac 配對。
- Mac 執行 MacReceiver，TextEdit 開新純文字文件，游標停在文件內。
- 備忘錄開新備忘錄，切換到 Remote Keyboard。
