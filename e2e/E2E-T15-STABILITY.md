# E2E-T15-STABILITY：穩定性與權限實機驗收

全部實機項目為 TBD，延至 T16，由使用者親手測完才算 PASS。自動驗證（Core 測試、Mac 測試、模擬器與真機 build、Release 符號檢查）見驗收報告 T15。

Wi-Fi／LAN WebSocket：N/A（D8，T06 已達標，不做）。

## 前置

- Mac：安裝 Debug 版 MacReceiver，已授權輔助使用，已配對；TextEdit 開新文件（純文字模式），游標在文件內。
- iPhone：安裝 Debug 版，鍵盤已開啟「允許完整取用」，遠端即時模式，連線狀態為已連線。
- Release 版沒有 burst 觸發與驗證按鈕，此測試只能用 Debug 版。

## A. 10,000 行 burst

觸發：遠端模式下長按「換行」4 秒（按住 2 到 4 秒放開，仍是原本送 3,000 字元的除錯動作）。狀態列顯示「burst n/10000」，完成顯示「burst 完成，已送 10000 行」。再長按 4 秒可中途取消。驗證：Mac 面板除錯區按「驗證 burst」，只顯示數字。

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| A1 | 長按「換行」4 秒，等到完成 | 10,000 行送完，iPhone 沒有卡住，可以再打字 | TBD |
| A2 | 按「驗證 burst」 | 預期 10000 行，遺漏 0，重複 0，亂序 0 | TBD |
| A3 | 重複 A1、A2 共 3 次（每次清空 TextEdit） | 三次都是 0／0／0 | TBD |
| A4 | burst 途中長按「換行」4 秒 | 立即停止，狀態列顯示已取消與已送行數；Mac 上的行數與已送行數相符，沒有重複 | TBD |
| A5 | burst 途中關閉 Mac 藍牙 | 中止，顯示「Mac 未就緒」或「等不到回覆」；不會自動補送 | TBD |
