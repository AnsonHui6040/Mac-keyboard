quick-table.txt (Remote Keyboard, Quick input method table)

Derived from the Cangjie table of libcangjie:
  https://gitlab.freedesktop.org/cangjie/libcangjie/-/raw/main/data/table.txt
  (file README: https://gitlab.freedesktop.org/cangjie/libcangjie/-/raw/main/data/README.table.md)

Legal statement of that data file, as published by its authors:

  "The data in the table.txt file is hereby placed under the Public Domain,
  in the hope that is is useful."

The authors state that the data was generated from the Unihan database of the Unicode Consortium, the Unicode
specification, the data of Wan Leung Wong's original libcangjie, and the work of the libcangjie team. Only the data
file is used here; no libcangjie program code (LGPL-3.0) is copied or linked.

Each Quick code in quick-table.txt is the first plus the last letter of a Cangjie code in that table, generated by
scripts/make-quick-table.swift.
