## 標題

Remote Keyboard v0.2：一支 iPhone 打字到 Mac、Windows、Linux

## 說明

Remote Keyboard 把 iPhone 變成電腦的藍牙鍵盤和觸控板。這支影片示範 v0.2.0 Alpha：同一支 iPhone 打字到 Mac、Windows 11 與 Ubuntu 26.04，點一下狀態格就換電腦，可以直接手寫中文，也可以改用速成輸入，鍵盤還能變成觸控板。

章節
0:00 一支 iPhone 打字到三部電腦：先打到 Mac
0:16 換到 Windows：手寫中文
0:28 換到 Linux：速成輸入
0:38 回到 Mac：觸控板
0:54 下載與安裝

下載
Release 頁面：https://github.com/AnsonHui6040/Mac-keyboard/releases/tag/v0.2.0-alpha.1
專案首頁：https://github.com/AnsonHui6040/Mac-keyboard
安裝教學：https://youtu.be/dGhEuzRpAEg

需求
iPhone：iOS 18 以上
電腦：macOS 15 以上（Apple 晶片）、Windows 11 或 Ubuntu 26.04
iPhone 透過 SideStore 安裝，不是 App Store 版本。

這是 Alpha 測試版，功能還會調整，也可能有問題，請不要用在重要工作上。本軟體依現狀提供，不提供任何保證。
