# Remote Keyboard v0.2 宣傳片：分鏡稿

PromoFilm，69.7 秒（2092 幀）、1920×1080、30 fps，台灣華語旁白（ElevenLabs，Anna Su，已由使用者批准）、合成音效。音樂尚未選定，第二階段加入。
秒數是 `video/src/promo/timeline.ts` 與 `cuts.ts` 算出來的實際值；幀號除以 30 就是秒。旁白的起訖是句子實際出聲的時間，前後各留 0.2 秒。第一版（64.6 秒）頭 18 秒太快，節奏修改（2026-11-18）放慢第 2、3、5 段，旁白不變，詳見文末「節奏修改」。

## 節奏修改（2026-11-18）

使用者看第一版後覺得頭 18 秒太快。旁白不改，只放慢畫面，片長由 64.6 秒變成 69.7 秒。

| 項目 | 第一版 | 修改後 |
|---|---|---|
| 第 2 段 | 9.5 秒 | 12.5 秒 |
| 第 3 段 | 3.1 秒 | 4.5 秒 |
| 第 5 段 | 3.2 秒 | 4.0 秒 |
| 即時模式打字 | 每 4 幀一鍵 | 每 6 幀一鍵 |
| 草稿模式打字 | 每 3 幀一鍵 | 每 5 幀一鍵 |
| 第 2 段鏡頭 | 手機、0.47 秒的 Mac、手機、Mac | 手機、Mac（字逐個長出，2.9 秒）、手機、Mac（整句落地，1.6 秒） |
| 點擊後到段落結束 | 較短 | 第 3 段 3.7 秒（110 幀）、第 5 段 3.0 秒（89 幀），都至少 2.5 秒 |

第 2 到 7 段每個特寫鏡頭至少 1.0 秒。
