# Remote Keyboard v0.2 宣傳片：分鏡稿

PromoFilm，64.6 秒（1938 幀）、1920×1080、30 fps，台灣華語旁白（ElevenLabs，Anna Su，已由使用者批准）、合成音效。音樂尚未選定，第二階段加入。
秒數是 `video/src/promo/timeline.ts` 與 `cuts.ts` 算出來的實際值；幀號除以 30 就是秒。旁白的起訖是句子實際出聲的時間，前後各留 0.2 秒。
