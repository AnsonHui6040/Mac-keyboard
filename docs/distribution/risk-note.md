# 測試前請先了解

Remote Keyboard v0.1.0 是測試版，安裝前請確認你接受以下事項。

| 項目 | 說明 |
|---|---|
| 來源 | 透過 SideStore 側載，不是來自 App Store 或 TestFlight，沒有經過 Apple 審查 |
| Mac App | 沒有經過 Apple 公證，第一次打開要到系統設定手動允許 |
| 鍵盤權限 | 需要開啟完整取用。請只在信任這個版本的來源時開啟 |
| Mac 權限 | Receiver 需要輔助使用權限，才能輸入文字與控制游標 |
| 密碼 | 請不要用這個鍵盤輸入密碼。一般密碼欄會被擋下，但部分終端機的密碼提示、遠端桌面內的欄位等可能偵測不到 |
| 觸控板 | Mac 鎖定時，已配對的 iPhone 仍可能移動和點按游標 |
| 第三方工具 | SideStore 與 LocalDevVPN 不是本專案的產品，也不是 Apple 的服務 |
| 有效期 | 免費帳號簽署的 App 只有 7 天有效，到期前要續簽 |
| 送達 | 連線不穩時，文字可能遺漏或重複。重要內容請送出前再檢查一次 |
| 資料 | 這是測試版，可能有未發現的問題。請勿用於重要工作，也請先備份 iPhone |

請不要把 Apple 帳號密碼或雙重驗證碼交給任何人，包括開發者。
