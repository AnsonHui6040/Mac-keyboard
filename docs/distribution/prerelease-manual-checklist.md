# 發佈前人手檢查清單

自動檢查用 `scripts/prerelease-check.sh`，結果在 `release/prerelease-report.md`。以下項目無法自動驗證，全部通過才發給測試者。重點項目標「必過」。

狀態：PASS、FAIL、BLOCKED、NOT TESTED。

實機結果來自開發簽署的 Debug 版本，不是 ad-hoc 簽署的 IPA 與 zip。
