# Remote Keyboard 安裝教學動畫設計

## 意圖

帶沒有程式背景的測試者，由零開始裝好 Remote Keyboard 並打出第一個字。測試者一邊看片一邊操作，所以每個畫面都要讓人知道：現在在哪部裝置、要按哪個按鈕、哪個不能按。

內容唯一來源是 `docs/video/install-tutorial-script.md`（21 場，約 5 分 13 秒）。腳本與手冊有出入時，以手冊為準；按鈕文字以台灣繁體中文系統字串為準。

## 目標

1. 測試者只看這條片，就能完成 iPhone 與 Mac 的安裝和配對。
2. 第 11 場（Extension 選第二個）與第 16 場（不要按藍色按鈕）不會看錯。
3. 片子沒有聲音，靜音播放也完全看得懂。

## 非目標

- 不教第 06 章以後的功能，例如手寫、觸控板、設定。
- 沒有旁白、背景音樂、音效。
- 不上傳、不放進 Release 或手冊。使用者說「部署」或「更新網頁」才做。
- 不做英文版。

## 反目標

以下任何一項出現，即使片子順利算出也算失敗：

- 標示線或標示框指錯按鈕。
- 出現真實 Apple 帳號、密碼、驗證碼、裝置名稱、UDID、路徑中的使用者名稱。
- 按鈕文字用了香港繁體中文字眼，例如「強制開啟」、「移至垃圾桶」、「私隱」、「軟件」。
- 模板感：hero 加三欄卡片、紫藍漸變、霓虹、大量粒子、` · ` 分隔字串、口號式文案。
- 成品出現製作備註、場景編號、解釋文字。

## 主代理的判斷（使用者可推翻）

| 項目 | 內容 | 原因 |
|---|---|---|
| 輸出 | 1920×1080、30fps、H.264 MP4，無音軌，字幕直接畫在畫面上 | 測試者多半在電腦或手機橫看；不必另外開字幕檔 |
| 位置 | 原始碼放 `video/`，有自己的 `package.json` | 不影響 Swift 專案與 `swift test` |
| 不入 git | `video/node_modules`、`video/out`、`video/public/fonts` | MP4 與字型都可以重新產生；字型三個檔共 21 MB，repo 是公開的 |
| 字型 | Noto Sans TC（Regular、Medium、Bold），由 `video/scripts/setup-fonts.sh` 從 `~/Library/Fonts` 複製 | OFL 授權可以用在影片；PingFang 是 Apple 字型，不用 |
| 字幕 | 用腳本「字幕」欄原文，按標點拆成多拍，一次一拍，每拍最多兩行、每行最多 30 字 | 沒有聲音，字幕要帶完整步驟；一次一拍才能和指向同步 |
| 每場時長 | 用腳本秒數，全片約 5 分 13 秒；每拍至少 2.5 秒，並以每秒 5 字估算閱讀時間 | 已估算全片閱讀加動作約 247 秒，腳本 310 秒放得下，多出的時間留給測試者操作 |
| 指向時間點 | `src/data/cues.json` 記每一拍字幕對應的目標按鈕 | 字幕與指向由同一份資料驅動，不會各走各的 |
| 裝置標籤 | 依目前要操作的裝置切換；兩部裝置同框時，正在操作的全亮，另一部降到 40% 亮度；沒有裝置的場景不顯示 | 觀眾任何時候都知道要看哪部裝置 |

## 視覺系統

沿用樣板的數值（樣板原始碼不在 repo，數值以這裡為準）。

| 項目 | 數值 |
|---|---|
| 舞台背景 | `#17181b` |
| 主要文字 | `#f2f1ee`，次要 `#9a9ba1`，分隔線 `#34363b` |
| 對話框 | 填色 `#26272b`，邊 `#4a4b50`，圓角 46，標題 `#f4f4f5` |
| 灰色線條 | `#4b4c52`，高 16，圓角 8，行距 38 |
| 中性按鈕 | 填色 `#3b3c41`，文字 `#f1f1f2` |
| macOS 藍按鈕 | `#2f7bf6` |
| 正確標示 | 框 `#35c46a`，文字 `#5fdc8f` |
| 錯誤標示 | `#ff5a4f` |
| 字幕 | Medium 46，置中，分隔線以下，y=920 |
| 裝置標籤 | 左上 (72, 72)，Medium 30，內容為「在 Mac 上」或「在 iPhone 上」 |
| 標示文字 | Bold 52，「按這個」、「不要按」 |

規則：

- 標示線是水平直線，由標示框右緣拉出，y 等於按鈕中心。
- 標示框與按鈕留 6 px，線寬 5，兩個相鄰的框不可相碰。
- 字幕不重複標示文字以外的資訊。標示只用兩三個字。
- 同一個畫面最多一個正確標示和一個錯誤標示。

## 畫面內容

重繪時，按鈕與標題的文字來源優先次序：系統字串表、手冊、截圖。

### 已由系統字串表確認

| 平台 | 字串 |
|---|---|
| macOS 27.2 | 強制打開、丟到垃圾桶、完成、隱私權與安全性、已阻擋「%@」以保護你的Mac。 |
| iOS 27.1 模擬器 | VPN與裝置管理、新增鍵盤、第三方鍵盤、開發者模式 |

### 第一次開工要先查

查法：`CoreServicesUIAgent.app`、`SecurityPrivacyExtension.appex` 的 `.loctable`，以及 iOS 模擬器 runtime 內 `zh_TW.lproj` 的 `.strings`。查不到就照手冊，並列入驗收報告。

- 「允許完整取用」完整字串。
- 「信任這部電腦？」標題與「信任」按鈕；「允許並重新啟動」。
- 系統設定輔助使用清單的標題。

### 沒有參考圖

第 5 場信任提示、第 6 場開發者模式、第 7 場 SideStore 登入、第 10 場 Finder 與終端機、第 11 場檔案選擇、第 15 場解壓縮。依系統慣例繪製，並在驗收報告標明「未對過實機」。

### 虛構內容

帳號：`your.name@example.com`。裝置名：「我的 iPhone」、「我的 Mac」。配對碼固定用虛構的 `482915`。終端機路徑用 `~/Downloads`，SHA-256 顯示完整 64 碼，寫死在專案裡，建置時不連網：IPA（`RemoteKeyboard-v0.1.0-unsigned.ipa`）為 `e66d8a72cf6d7f3533e5ce22afdb8f78154f94c9aecfac62b0463444e966753f`，zip（`RemoteKeyboardReceiver-v0.1.0-macOS.zip`）為 `f9b5f22650539eab6def4bdcae8247763ff13d6325946f22d413fe3b5c40854a`。第 20 場 Receiver 面板「目前欄位」顯示「文字編輯（可輸入）」。

## 動態

- 每場：裝置框淡入後，每一拍字幕出現時，指向移到該拍的目標，鏡頭視需要推近。
- 指向：Mac 上是標準箭頭游標，移到目標後做一次點按動畫；iPhone 上是半透明白色圓點，做一次輕點波紋。指向先到目標、停 0.5 秒，才做點按。
- 「按這個」、「不要按」與標示框只用在第 11、16 場這兩個容易做錯的地方，其他場只用指向。第 11 場電話內的選項字很小（實機亦然），另在電話左方放大顯示完整文字。
- 時長用 `spring` 或 `interpolate` 推導自幀數，全部是幀的純函數。
- 第 16 場：跟字幕順序，先出現正確標示，下一拍出現錯誤標示；兩個標示同時停留至少 3 秒。第 11 場同樣停留至少 3 秒。
- 換場用淡入淡出，不做 3D、粒子、抖動。

## 製作結構

```
video/
  package.json、tsconfig.json
  scripts/setup-fonts.sh       複製 Noto Sans TC
  scripts/gen-script-data.mjs  由腳本表格產生 script.json
  src/index.tsx                註冊 Main 與每場的獨立 composition
  src/theme.ts                 視覺系統的數值
  src/components/              IPhoneFrame、MacDialog、MacWindow、SettingsList、Callout、Subtitle、DeviceTag、SkeletonLines
  src/screens/                 各畫面
  src/scenes/Scene01.tsx ...   21 場
```

`script.json` 由 `docs/video/install-tutorial-script.md` 的表格產生，不手寫第二份字幕。

## 驗收

驗收報告放 `docs/superpowers/verification/2026-11-04-install-tutorial-video.md`。

### 自動驗證

1. `kinetograph check`、`lint`（每場開頭、中間、結尾）、`doctor` 無錯誤。
2. 用 `kinetograph inspect` 核對每條標示線的 y 等於目標按鈕中心，以及每個指向停留時落在目標按鈕範圍內，誤差 1 px 內。逐條列出。
3. MP4 無音軌（`ffprobe` 確認）。
4. 每一拍字幕顯示時間不短於 2.5 秒與「字數 ÷ 5」；每拍不超過兩行。
5. grep 原始碼：沒有「強制開啟」、「移至垃圾桶」、「私隱」、「軟件」、廣東話字、` · `、真實帳號或裝置名。
6. 每場 `strip` 由主代理親自看過，不採信子代理的自我報告。
