## 2. 實機項目（全部 TBD）

### 準備

1. repo 根目錄：`scripts/rime/fetch.sh`、`scripts/rime/build-xcframework.sh`、`xcodegen generate`、`LANG=en_US.UTF-8 pod install`。
2. iPhone 已在主 App 下載手寫模型，並已加入鍵盤且允許完整取用。
3. 量測行只在 DEBUG build 出現；以下指令是 Debug 測試，跑完要把 Release 版本重新裝回 iPhone（觸控板在 Debug 版會卡）。
4. 每次一條指令，輸出的 `RKMEAS RIME ...` 行貼回給我。把 `<iPhone 名稱>` 換成裝置名稱。

### 指令

R1，librime：

```bash
TEST_RUNNER_RKMEAS_QUICK_ENGINE=rime xcodebuild test -workspace RemoteKeyboard.xcworkspace -scheme RemoteKeyboardApp -destination 'platform=iOS,name=<iPhone 名稱>' -only-testing:RemoteKeyboardUITests/RimeMeasurementUITests 2>&1 | grep RKMEAS
```

R2，Swift 速成（比較用）：

```bash
TEST_RUNNER_RKMEAS_QUICK_ENGINE=swift xcodebuild test -workspace RemoteKeyboard.xcworkspace -scheme RemoteKeyboardApp -destination 'platform=iOS,name=<iPhone 名稱>' -only-testing:RemoteKeyboardUITests/RimeMeasurementUITests 2>&1 | grep RKMEAS
```

R3：先在 iPhone 設定把 Remote Keyboard 的「允許完整取用」關掉，再跑 R1 的同一條指令（引擎維持 `rime`）。

- 模擬器上 `RimeMeasurementUITests` 會自動略過；模擬器的啟動時間（約 1 毫秒）不是實機數字。
