## 7. 常用指令

- 產生專案：`xcodegen generate`，接著 `LANG=en_US.UTF-8 pod install`（沒有 UTF-8 會當機）；之後一律用 `-workspace RemoteKeyboard.xcworkspace`。
- Core 測試：`swift test --package-path Packages/RemoteKeyboardCore`（`main` 525）。
- iOS 真機 build：`xcodebuild build -workspace RemoteKeyboard.xcworkspace -scheme RemoteKeyboardApp -destination 'generic/platform=iOS' -allowProvisioningUpdates -derivedDataPath <路徑>`
- 模擬器 build：`-destination 'platform=iOS Simulator,name=iPhone 18 Pro,OS=27.0' CODE_SIGNING_ALLOWED=NO`（ML Kit 只連結真機，模擬器用空殼）。
- 安裝到 iPhone：`xcrun devicectl device install app --device 00008150-000C65DA26C0401C <路徑>/Debug-iphoneos/RemoteKeyboardApp.app`
- Mac 測試：`xcodebuild test -scheme MacReceiver -destination 'platform=macOS,arch=arm64' -allowProvisioningUpdates`（164）。
- Mac Receiver 執行：build 後複製到 `/private/tmp/claude-501/receiver-run/MacReceiver.app` 再 `open`。
- Mac 紀錄：`/usr/bin/log stream --info --predicate 'subsystem == "com.ansonhui.remotekeyboard.receiver"'`（要寫 `/usr/bin/log`，`log` 會與 zsh 內建指令衝突）。
- 截圖：主 App 以 `-rkPreview <狀態>` 啟動（`local`、`remoteInstant`、`remoteDraft`、`notReady`、`symbols`、`caps`、`handwriting`、`dictationProbe`）；402 pt 用 iPhone 18 Pro 模擬器（與使用者的 iPhone 17 Pro 同寬），375 pt 用 iPhone SE 3 模擬器。
- 自動實機測試：`e2e/scripts/t10-device-run.sh`（iPhone 需解鎖、自動鎖定設為永不；TextEdit 只寫入腳本自己的執行資料夾）。
