## 重新輸出

先把兩條音樂放到 `video/public/audio/`（`Clean_Geometry.mp3`、`Soft_Geometry.mp3`）。授權未確認，檔案不進 git。

```bash
cd video
scripts/render-film.sh
```

腳本先輸出 `product-film-raw.mp4`，再做音量與限幅，視訊串流不重新編碼。

`video/public/film/env.png` 是程式產生的黑底漸層環境光貼圖（1024×512），不含照片或第三方素材。

## 聲音量測

方法：用 `--range 0..1514` 輸出只有音樂的音軌（`ProductFilm` 的音效只在整片長度的音訊 context 播放），整片輸出減去它就是音效。取每個音效事件後 60 ms 的音效峰值，比同一事件前後各 0.5 秒的音樂峰值。這是母帶（響度與限幅）之前的原始檔；限幅會讓母帶後的差距小一些。對齊檢查：沒有事件的第 296 到 305 幀，殘差 -66.7 dBFS。

| 項目 | 中位數 | 最小到最大 | 目標 |
|---|---|---|---|
| 按鍵聲，3 到 12 秒（有音樂，新） | +7.2 dB（39 個） | +4.8 到 +21.9 | +6 到 +8，達標 |
| 輕點聲，3 到 29 秒 | +6.5 dB（15 個） | +3.4 到 +21.5 | 達標 |
| 按鍵聲，第 30 鏡（41 到 44 秒） | +6.6 dB（15 個） | +0.6 到 +14.7 | 達標 |
| 按鍵聲，16 到 29 秒 | +5.5 dB（4 個） | +1.6 到 +12.6 | 略低 |
| 點按聲，29 到 41 秒 | +1.5 dB（7 個） | -0.3 到 +2.4 | 未達標 |
| 手寫 ink | -0.7 dB（18 個） | -4.5 到 +3.4 | 設計上極輕 |

為了讓按鍵聲達標，開場一段音樂（0 到 12.2 秒）基礎音量由 0.62 降到 0.5，最後一段（41.5 到 49.5 秒）由 0.7 降到 0.45；音效沒有動。

第 1 秒有音樂：音樂音軌第 0 到 1 秒 RMS -23.7 dBFS、峰值 -8.3 dBFS；成品檔第 0 到 1 秒平均 -20.6 dB、峰值 -4.9 dBFS，第 0 到 0.3 秒平均 -16.7 dB；`ebur128` 瞬時響度在第 0.4 秒 -15.4 LUFS。音樂從第 0 秒起（來源第 0.058 秒），第 1 幀以半音量進入，沒有單獨量測到爆音。
