### 獨立審查

另寫 Python 照規則 1–7 重算，扣除 U+FA0C、U+FA0D 後兩份詞典逐行相同（字、碼、權重、次序）；大千鍵位 41 字逐一核對無誤。結論 APPROVE，Critical 0、Important 0、Minor 4：

1. U+FA0C、U+FA0D 依 canonical equivalence 併入 U+5140、U+55C0（與 Task 1 相同）；這兩字在 `phrase.occ` 次數為 0，不影響使用。
2. 命令列未斷言 `key_mismatches == 4`：來源已以 SHA-256 鎖定，維持只印出。
3. `phrase.occ` 有 3 個重複詞（亞美尼亞、強子、雅美族），只取第一筆，權重為 1。
4. `utf8` 類別單字含簡體字：照計畫由 Task 4 品質報告列出，交使用者決定。

交給 Task 4 的事項：拼音方案的 speller 需加 `nue→nve`、`lue→lve` 等 derive；整句型方案的 delimiter 含空白。
