### 常用口語詞權重

拼音、注音詞典的詞頻來自 McBopomofo，偏書面語，所以只打聲母時「你好」（`nh`）排第 11，前面是女孩、年後、男孩等。產生詞典時改為讀入本專案自行整理的清單 `ime/sources/colloquial-boost.txt`（44 個詞），補高這些詞的權重。粵拼詞典用另一份資料，不受影響。

規則（`ColloquialBoost`，由 `make-ime-dicts --boost` 啟用）：

| 項目 | 做法 |
|---|---|
| 簡拼鍵 | 詞的碼每個音節取第一個字元（拼音 `ni hao` 為 `nh`；注音「你好」為 `sc`）。注音音節的第一個鍵不是聲母時改用見下一節 |
| 新權重 | max(原權重，同詞典內音節數與簡拼鍵相同、且不在清單的詞的最大權重 + 1)，權重只升不降，單字不受影響 |
| 清單內撞鍵 | 清單較前的詞排前面 |
| 多個讀音 | 每個碼各自計算 |
| 清單詞不在詞典、單字詞、重複詞 | 產生器失敗並印出該詞，不會略過 |
