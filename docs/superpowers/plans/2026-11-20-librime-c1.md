# librime C1 技術驗證 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以 librime 取代速成的組字引擎（Swift 速成保留作後備），並量出 librime 在鍵盤擴充程式內的記憶體、延遲與 App 大小。

**Architecture:** 建置腳本以固定版本原始碼編譯 `RimeC.xcframework`（iOS 實機、iOS 模擬器、macOS 三個 slice），本地 SwiftPM 套件 `RimeEngine` 包一層 Swift，並提供 `RimeInputMethod: ChineseInputMethod`。速成方案與詞典放在共用資料夾 `ime/rime/`，建置時以 macOS 的 `rime_deployer` 預先編譯，放進鍵盤 bundle；鍵盤只讀預先編譯好的檔案。

**Tech Stack:** C++17、CMake、librime 1.17.0、Boost 1.92.0（只用標頭）、LevelDB 1.23、marisa-trie 0.3.1、yaml-cpp 0.9.0、OpenCC 1.4.2；Swift 6、SwiftPM、XcodeGen、CocoaPods（現有）、XCTest。

**Spec:** `docs/superpowers/specs/2026-11-20-librime-input-engine-design.md`（D31，§7.1 為本計畫範圍）

## Global Constraints

- 部署目標 iOS 18.0、macOS 15.0；Swift language mode 6（同 `project.yml` 與 `RemoteKeyboardCore`）。
- 原始碼版本固定於 `scripts/rime/versions.lock`，下載後核對 SHA-256（M13）；不要求產物逐位元相同，不新增 iOS CI。
- librime 以 `ENABLE_LOGGING=OFF`、`BUILD_TEST=OFF`、靜態庫建置；不編入 librime-lua 與任何外掛（M3）。
- 方案設定 `enable_user_dict: false`（M4）；鍵盤執行時不編譯詞典（M2）。
- `RimeC.xcframework` 不提交，放在 git 忽略的 `Packages/RimeEngine/Artifacts/`（M6）；`build/` 已被忽略。
- 速成規則與收字和現有 `scripts/make-quick-table.swift` 完全相同：Big5 字、倉頡第五代碼（沒有時用第三代）取首尾碼、同碼依排序值由高到低（U7：C1 仍只收 Big5）。
- 本計畫不刪除 Swift 速成（`QuickInputMethod`、`QuickDictionary`、`quick-table.txt`）；實機通過後另開 Task 刪除（U4、U6）。
- log 只記事件種類、數量、時間與結果，不記打過的文字、輸入碼或候選字。
- 子代理不得 commit 或 push；每個 Task 結束時由主代理重跑驗證後 commit。
- Xcode 專案由 XcodeGen 產生：改 `project.yml` 後執行 `xcodegen generate`，再 `LANG=en_US.UTF-8 pod install`；build 一律用 `-workspace RemoteKeyboard.xcworkspace`。
- 產品文字用台灣繁體中文用字。

## Review Focus

1. 鍵盤反覆出現與消失（擴充程式行程不一定結束）：librime 只能在同一行程初始化一次；第二次啟動要沿用，不得重複初始化或當掉。測試在 Task 2。
2. bundle 內的預先編譯資料缺少或損壞：建立 session 或健康檢查（`isHealthy`）失敗，鍵盤改用 Swift 速成，不得當掉。測試在 Task 2（`testHealthCheckFailsWhenDictionaryIsMissing`）與 Task 5（`QuickEngineChoiceTests`）。
3. librime 還在載入時就按鍵：按鍵不得遺失或亂序；按鍵次序由現有 `OrderedActionQueue` 保證，載入只做一次由 `OnceLoader` 保證。測試在 Task 5（`OnceLoaderTests`）。
4. 非英文字母的按鍵（全形字、表情符號、數字）送進速成：一律 pass through，不送進 librime。測試在 Task 4。
5. 打字期間 librime 在 `staging_dir` 產生新的 `.bin`（等於在鍵盤內編譯）：測試在 Task 2，實機量測在 Task 6。

```swift
final class RimeRuntimeTests: XCTestCase {
    func testStartsFromPrebuiltDataWithoutDeploying() throws {
        let paths = try RimeFixture.compiled("fixture")
        let session = try RimeRuntime.start(paths).makeSession(schema: "fixture")
        XCTAssertTrue(session.processKey(Int32(UInt8(ascii: "a"))))
        XCTAssertTrue(session.processKey(Int32(UInt8(ascii: "b"))))
        XCTAssertEqual(session.state, RimeState(input: "ab", candidates: ["明", "盟"]))
    }
    func testSecondStartWithSamePathsReusesRuntime() throws {
        let paths = try RimeFixture.compiled("fixture")
        XCTAssertTrue(try RimeRuntime.start(paths) === RimeRuntime.start(paths))
    }
    func testStartWithOtherPathsThrows() throws {
        let paths = try RimeFixture.compiled("fixture")
        _ = try RimeRuntime.start(paths)
        var other = paths; other.userData = paths.userData.appending(path: "other")
        XCTAssertThrowsError(try RimeRuntime.start(other)) { XCTAssertEqual($0 as? RimeError, .alreadyStartedWithOtherPaths) }
    }
    func testUnknownSchemaThrows() throws {
        let runtime = try RimeRuntime.start(RimeFixture.compiled("fixture"))
        XCTAssertThrowsError(try runtime.makeSession(schema: "missing")) { XCTAssertEqual($0 as? RimeError, .schemaUnavailable("missing")) }
    }
    func testSelectCandidateCommitsIt() throws {
        let session = try RimeRuntime.start(RimeFixture.compiled("fixture")).makeSession(schema: "fixture")
        _ = session.processKey(Int32(UInt8(ascii: "a"))); _ = session.processKey(Int32(UInt8(ascii: "b")))
        XCTAssertTrue(session.selectCandidate(1))
        XCTAssertEqual(session.takeCommit(), "盟")
        XCTAssertEqual(session.state, RimeState(input: "", candidates: []))
    }
    func testHealthCheckFailsWhenDictionaryIsMissing() throws {
        let runtime = try RimeRuntime.start(RimeFixture.compiled("fixture"))
        XCTAssertTrue(try runtime.makeSession(schema: "fixture").isHealthy(probeKey: "a"))
        let broken = try? runtime.makeSession(schema: "broken")
        XCTAssertFalse(broken?.isHealthy(probeKey: "a") ?? false)
    }
    func testTypingDoesNotCompileIntoStaging() throws {
        let paths = try RimeFixture.compiled("fixture")
        let session = try RimeRuntime.start(paths).makeSession(schema: "fixture")
        for key in "ablab" { _ = session.processKey(Int32(key.asciiValue!)) }
        let staging = paths.userData.appending(path: "build")
        let bins = (try? FileManager.default.contentsOfDirectory(atPath: staging.path))?.filter { $0.hasSuffix(".bin") } ?? []
        XCTAssertEqual(bins, [])
    }
}
```
