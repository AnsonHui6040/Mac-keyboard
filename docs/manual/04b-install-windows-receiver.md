# 04b 安裝 Windows 接收端

Windows 接收端是安裝在 Windows 電腦上的接收程式。iPhone 傳來的文字與觸控板動作，由它輸入到電腦目前在最前面的視窗。它沒有主視窗，只在工作列右側的通知區域顯示一個圖示。

這一章只適用於 Windows 電腦。Mac 請看 [04 安裝 Mac Receiver](04-install-mac-receiver.md)，Ubuntu 請看 [04c 安裝 Linux 接收端](04c-install-linux-receiver.md)。

## 需求

| 項目 | 需求 |
|---|---|
| 作業系統 | Windows 11，x64 |
| 藍牙 | 電腦有藍牙（支援 Bluetooth LE），而且已開啟 |
| 權限 | 一般使用者帳號即可，安裝時不需要系統管理員 |
| 網路 | 接收端運作時不需要網路，文字只經藍牙傳送 |

這個版本沒有數位簽章，第一次執行時 Windows 會顯示 SmartScreen 警告，需要手動允許。

## 一、下載、驗證並安裝

1. 從 GitHub Release 取得安裝檔 `RemoteKeyboard-Setup-0.2.0-alpha.1.exe`，以及同一頁的 `SHA256SUMS.txt`。
2. 打開 PowerShell，執行下面的指令，把檔案路徑換成你的安裝檔位置。

```powershell
Get-FileHash .\RemoteKeyboard-Setup-0.2.0-alpha.1.exe -Algorithm SHA256
```

3. 比對輸出的 Hash 與 `SHA256SUMS.txt` 裡該檔案的值，兩者必須完全相同。值不同時請重新下載，不要安裝。
4. 連按兩下安裝檔，依畫面指示安裝。

安裝程式把接收端裝在 `%LOCALAPPDATA%\Programs\RemoteKeyboard`，不會要求系統管理員權限。安裝程式裡的「開機時自動啟動」選項預設已勾選。不想在登入後自動執行，安裝時取消勾選，之後也可以在系統匣選單的「開機自動啟動」更改。最後一頁可以選擇立即啟動。

## 二、第一次執行

第一次執行安裝檔時，Windows 顯示「Windows 已保護您的電腦」。

1. 按「其他資訊」。
2. 按出現的「仍要執行」。

成功時，安裝程式開啟，完成後接收端啟動，工作列右側出現 Remote Keyboard 的圖示。圖示被收在「^」裡面時，按「^」展開，把圖示拖到工作列上，之後就會固定顯示。

## 三、開啟藍牙

1. 打開「設定 > 藍牙與裝置」，確認「藍牙」是開啟的。
2. 系統匣圖示的提示文字顯示「藍牙未開啟，無法掃描」時，代表藍牙目前是關的，開啟後接收端會自動恢復掃描。

接收端用藍牙與 iPhone 連線，不需要先在 Windows 的藍牙清單加入 iPhone。

成功時，系統匣圖示的提示文字顯示「接收中，等待手機連線」。

## 四、系統匣選單

點系統匣的 Remote Keyboard 圖示，打開選單。選單的文字依 Windows 的顯示語言決定，使用中文時顯示下表的中文，其他語言顯示英文。

| 項目（中文） | 項目（英文） | 說明 |
|---|---|---|
| 第一行（狀態）：接收中，等待手機連線、已連線：手機名稱、配對中，請在手機上開啟配對畫面、已停止接收 | Receiving, waiting for a phone; Connected: phone name; Pairing: open the pairing screen on the phone; Receiving stopped | 目前的狀態。這一行不能按 |
| 停止接收、開始接收 | Stop receiving、Start receiving | 「停止接收」會中斷目前連線並停止掃描，直到按「開始接收」或重新啟動接收端才恢復。「已停止」不會存入設定，重新啟動後一律接收中 |
| 電腦名稱　改名… | Computer name　Rename… | 這一行以目前的電腦名稱開頭，預設是「Windows」。按下去會出現輸入框，用來改這台電腦在手機上顯示的名稱，最多 32 個位元組。改名後，已配對的 iPhone 要重新配對才會顯示新名稱 |
| 配對新手機 | Pair a new phone | 開始配對，見 [05 配對](05-pairing.md)。已停止接收時不能按 |
| 已配對的手機 | Paired phones | 列出已配對的手機。選一支手機，再按「刪除」，就解除這支手機的配對。沒有任何手機時顯示「尚未配對任何手機」。最多可以配對 8 支 |
| 允許觸控板控制 | Allow trackpad control | 勾選時，iPhone 可以控制游標，見 [07 觸控板](07-trackpad.md) |
| 開機自動啟動 | Start at sign-in | 勾選時，登入 Windows 後自動執行接收端 |
| 匯出診斷資料 | Export diagnostics | 在桌面產生診斷用的 zip 檔，內容見 [接收端排錯](../troubleshooting-receiver.md) |
| 結束 | Quit | 結束接收端，iPhone 就無法連到這台電腦 |

接收端有訊息要你處理時，圖示的提示文字會顯示下列其中一句，中文或英文依顯示語言：

| 提示文字 | 處理 |
|---|---|
| 這支手機需要重新配對 | 在手機與電腦兩邊重新配對 |
| 請更新 iPhone App | 把 iPhone App 更新到同一版 |
| 配對失敗，請再試一次 | 重新按「配對新手機」 |
| 已配對 8 支手機，請先刪除一支 | 到「已配對的手機」刪除不用的手機 |
| 無法儲存配對資料 | 重新配對；仍失敗就匯出診斷資料 |
| 藍牙未開啟，無法掃描 | 開啟 Windows 的藍牙 |
| 設定檔無法讀取，也無法備份；這次的設定不會儲存，原檔保持不動 | 匯出診斷資料，見 [接收端排錯](../troubleshooting-receiver.md) |

## 五、升級與解除安裝

| 情況 | 做法 |
|---|---|
| 升級 | 直接執行新的安裝檔。安裝程式會先關閉執行中的接收端，裝好後再啟動。設定與配對都保留 |
| 從 v0.1 升級 | 這個版本的通訊協定是 v4，與 v0.1 不相容。iPhone App 與 Mac Receiver 都要更新，所有電腦都要重新配對 |
| 解除安裝 | 到「設定 > 應用程式」找到 Remote Keyboard，按「解除安裝」。開機自動啟動的設定會一併移除 |

設定檔在 `%APPDATA%\RemoteKeyboard`，log 在 `%LOCALAPPDATA%\RemoteKeyboard\logs`。解除安裝不會刪除這兩個位置，重新安裝後不必重新配對。要完全清除，自行刪除這兩個資料夾。

## 六、使用時要知道的事

| 項目 | 說明 |
|---|---|
| 沒有焦點安全閘 | Windows 接收端不判斷目前的欄位是什麼。文字會送到目前最前面的視窗，包括密碼欄。要打字前，先確認游標在你要輸入的欄位，不要用這個鍵盤輸入密碼 |
| 系統管理員視窗 | 以系統管理員身分執行的視窗、UAC 提示與鎖定畫面收不到輸入。接收端本身不以系統管理員身分執行，遇到這種視窗，請改用一般權限開啟 |
| 連不上時 | iPhone 的 Remote Keyboard 鍵盤要在畫面上，接收端才會連線。先看系統匣的第一行狀態是不是「已停止接收」 |

成功時，iPhone 鍵盤的狀態格顯示這台電腦的名稱與「已連接」。

完成之後，接收端已經可以和 iPhone 配對。
